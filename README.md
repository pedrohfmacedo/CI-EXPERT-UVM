# CI-Expert - Workspace de Laboratórios

Este repositório reúne os materiais, exercícios e projetos desenvolvidos no programa CI-Expert, na trilha de Verificação Digital. A estrutura foi organizada para registrar a evolução do aprendizado em automação, RTL, testbenches, UVM e fluxo de trabalho de laboratório.

## Objetivo

Documentar e centralizar os laboratórios executados no workspace, incluindo:

- organização de projetos HDL
- automação com scripts de geração
- criação e execução de testbenches
- prática com Verilog/SystemVerilog
- introdução e aplicação de UVM
- registros de aulas e anotações em arquivos de texto

## Estrutura do workspace

A estrutura principal do repositório está organizada na pasta `workspace/labs`, com os seguintes módulos:

### 1. `workspace/labs/s1`
Concentra os primeiros exercícios de organização de projeto e estruturação de diretórios. É a base para os laboratórios iniciais e a compreensão do fluxo de desenvolvimento.

### 2. `workspace/labs/s5`
Inclui exercícios de circuitos digitais em Verilog, como multiplexadores, demultiplexadores, somadores, contadores e outros blocos combinacionais e sequenciais. Também contém as estruturas de projeto e comandos de simulação.

### 3. `workspace/labs/s6`
Foca em projetos mais elaborados, como robô/controle e exemplos de automação de verificação com organização em diretórios e arquivos de configuração e simulação.

### 4. `workspace/labs/s8-9`
Contém os laboratórios relacionados a UVM, com materiais de prática e estudo das partes 1 e 2 do treinamento. É a base para a implementação de ambiente de verificação em SystemVerilog/UVM.

### 5. `workspace/labs/uvm-pratice`
Área de exercícios práticos para reforço do uso de UVM, estruturas de agentes, drivers, sequencers, monitor e ambiente de teste.

### 6. `workspace/labs/minisoc-tag-v1.0`
Projeto mais completo do workspace, contendo elementos de arquitetura e verificação com foco em SoC/RTL e atividades de validação e análise de comportamento.

## Anotações de aula

Além dos exercícios, o repositório inclui arquivos de anotação das aulas, com registros do conteúdo abordado em sala, por exemplo:

- `anotacao-aula-2-25.03.2026.txt`
- `anotacao-aula-3-01.04.2026.txt`
- `anotacao-aula4-08.04.2026.txt`

Esses arquivos servem como histórico do aprendizado e apoio para revisão posterior.

## Visão geral do aprendizado

Durante o curso, foram praticados os seguintes tópicos:

- organização de repositórios e branches Git
- criação e uso de arquivos de documentação
- estruturação de projetos RTL
- desenvolvimento de testbenches
- uso de scripts de automação
- familiarização com Verilog/SystemVerilog
- noções de verificação funcional e UVM
